# US-10.1 — Temas desde el panel

| | |
|---|---|
| **Épica** | EP-9 — Temas |
| **Rol** | Autora/or del contenido |
| **Requisitos** | [RF-9.1](../06-requisitos.md), [RF-9.2](../06-requisitos.md) |

## Descripción

Como **autora/or del contenido** quiero **cambiar los colores y la tipografía de la web
desde el panel** para **ajustar la identidad del sitio sin tocar código ni desplegar**.

## Criterios de aceptación

**Dado** el panel en «Temas»,
**cuando** creo un tema con un nombre y sus variables,
**entonces** aparece en la lista y puedo activarlo.

**Dado** un tema activo,
**cuando** recargo la web,
**entonces** los colores, líneas y acento son los del tema.

**Dado** dos temas,
**cuando** activo uno,
**entonces** el otro queda inactivo (solo hay un tema activo).

**Dado** el tema activo,
**cuando** intento borrarlo,
**entonces** la API lo impide (422) hasta activar otro.

## Definición de Hecho

- Tabla `themes` (`name`, `slug`, `tokens` JSON, `is_active`).
- CRUD en `/api/v1/admin/themes` + `POST /themes/{id}/activate`.
- `GET /api/v1/site` incluye `theme` con los tokens activos.
- La web aplica los tokens como variables CSS en `:root`.
