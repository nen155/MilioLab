# US-11.1 — Tema «Nodos» (grafos y morado)

| | |
|---|---|
| **Épica** | EP-10 — Nodos |
| **Rol** | Autora/or del contenido |
| **Requisitos** | [RF-10.1](../06-requisitos.md) |

## Descripción

Como **autora/or del contenido** quiero **un tema morado con estética de grafo** para
**que la web se sienta como el árbol de escenas de Cinema Decisive**.

## Criterios de aceptación

**Dado** el panel en «Temas»,
**cuando** activo «Nodos»,
**entonces** la web usa fondo oscuro morado, rejilla de puntos y acento violeta.

**Dado** el tema «Nodos» activo,
**cuando** abro la portada,
**entonces** las entradas aparecen como **nodos encadenados** con puertos y conectores.

**Dado** el tema «Nodos» activo,
**cuando** cambio a «Cuaderno de laboratorio»,
**entonces** la web vuelve al papel claro sin perder contenido.

## Definición de Hecho

- Tema sembrado `nodos` con tokens morados (`--paper`, `--ink`, `--accent`…).
- Bloque CSS `[data-theme="Nodos"]` para rejilla de puntos, brillos y nodos.
- `NodeMapComponent` en la portada con conectores y puertos.
- Se puede volver al tema anterior desde «Temas».
