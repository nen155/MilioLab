# US-10.2 — Crear, exportar e importar temas

| | |
|---|---|
| **Épica** | EP-9 — Temas |
| **Rol** | Autora/or del contenido |
| **Requisitos** | [RF-9.3](../06-requisitos.md), [RF-9.4](../06-requisitos.md) |

## Descripción

Como **autora/or del contenido** quiero **exportar un tema a JSON, crear otros desde cero
e importar temas hechos en otro sitio** para **reutilizar estilos y probar variantes**.

## Criterios de aceptación

**Dado** un tema guardado,
**cuando** pulso «Copiar JSON»,
**entonces** obtengo `{ "name": "…", "tokens": { "…": "…" } }` listo para pegar.

**Dado** un JSON pegado en «Importar tema»,
**cuando** pulso «Importar»,
**entonces** se crea el tema (y se activa si marco la casilla).

**Dado** un JSON inválido o sin `name`/`tokens`,
**cuando** lo importo,
**entonces** veo un error claro y no se crea nada.

**Dado** un tema con variables desconocidas o valores peligrosos (`}` `;` `<`),
**cuando** se guarda o importa,
**entonces** esas variables se descartan.

## Definición de Hecho

- `POST /api/v1/admin/themes/import` con el mismo formato que la exportación.
- `Theme::ALLOWED_TOKENS` como lista blanca y `sanitizeTokens()` como filtro.
- Editor de variables en el panel con selector de color para las claves de color.
- Copiar JSON desde la lista de temas.
