# US-11.3 — Mapa de nodos: navegación, rendimiento y ramas

| | |
|---|---|
| **Épica** | EP-10 — Nodos |
| **Rol** | Visitante |
| **Requisitos** | [RF-10.3](../06-requisitos.md), [RNF-10](../06-requisitos.md) |

## Descripción

Como **visitante** quiero **recorrer el mapa de nodos con el teclado y sin que los
vídeos consuman recursos de fondo** para **explorar el grafo con comodidad y en móvil**.

## Criterios de aceptación

**Dado** el mapa de nodos,
**cuando** pulso `←` / `→` / `Inicio` / `Fin`,
**entonces** el foco salta entre nodos con *roving tabindex* (un solo `tabindex=0`).

**Dado** un nodo fuera de la pantalla,
**cuando** hago scroll,
**entonces** su vídeo se pausa; al volver a la vista se reanuda (si el usuario no lo pausó).

**Dado** el primer nodo,
**cuando** se pinta,
**entonces** se marca como **origen** con puerto relleno y halo del acento.

**Dado** una pantalla menor de 760 px,
**cuando** abro el mapa,
**entonces** los nodos se apilan en vertical con conectores verticales y el extracto visible.

## Definición de Hecho

- `NodeMapComponent`: roving tabindex, teclas de navegación, nodo origen y etiqueta de rama.
- `NodeVideoComponent`: `IntersectionObserver` (umbral 25 %) y respeto a la pausa manual.
- Estilos responsive del grafo y extracto al hover/focus.
